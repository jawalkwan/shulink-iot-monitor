# 运行监控

「运行监控」页是设备的运行时仪表盘：实时值、运行值修改、随机模拟与通信日志都在这里。

## 实时值查看

- 展示各从站四类内存区（线圈 / 离散输入 / 输入寄存器 / 保持寄存器）的当前运行值
- 默认开启**自动刷新**（周期轮询后端运行态），可手动关闭
- 结合寄存器名称、单位展示，等同真实传感器面板

## 在线修改运行值

- 直接在监控页修改任意寄存器的运行值，效果等同主站写入
- 可用于模拟主站下发控制指令后的设备状态变化
- 运行值只写入内存，不回写配置文件（配置初值保持不变）

## 随机模拟

在监控页可直接为寄存器开启 / 停止随机模拟，详见 [[Random-Simulation|随机模拟]]。

## 通信日志

每台设备维护独立的**环形日志缓冲（500 条）**，超出自动淘汰最旧记录：

| 日志类型 | 前缀 / 内容 |
|---|---|
| Modbus 请求 | `[RX]` 从站号、功能码、地址、数量、报文 HEX / ASCII |
| Modbus 响应 | `[TX]` 功能码响应、报文 HEX / ASCII |
| 注册包 | `[REG]` 发送结果与字节数 |
| 心跳 | `[HB]` 发送结果与字节数 |
| 连接事件 | 连接 / 断开 / 重连 / 错误信息 |

- HEX 视图：原始字节流十六进制；ASCII 视图：可打印字符直接显示，不可打印字符显示为 `.`
- 日志可在界面中清空
- 端到端联调时，配合主站侧抓包可完整对账每一次交互
