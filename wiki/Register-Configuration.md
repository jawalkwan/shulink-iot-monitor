# 寄存器配置

## 四类内存区

每个从站独立维护标准 Modbus 四类内存区：

| 内存区 | 地址前缀 | 读写 | 说明 |
|---|---|---|---|
| 线圈 Coils | 0x | 读 / 写 | 位寄存器（0 / 1） |
| 离散输入 Discrete Inputs | 1x | 只读 | 位寄存器（0 / 1） |
| 输入寄存器 Input Registers | 3x | 只读 | 16 位寄存器 |
| 保持寄存器 Holding Registers | 4x | 读 / 写 | 16 位寄存器 |

- 每区最多 **10,000 个地址**（Modbus 地址空间 = 该区数组长度）
- 位区数据类型固定为 `bool`；寄存器区支持 `uint16` / `int16` / `uint32` / `int32` / `float32`

## 寄存器条目

每条寄存器可配置：

| 字段 | 说明 |
|---|---|
| 名称 | 仅用于展示，不参与 Modbus 通信 |
| 初值 | 配置初值（0–65535，位区 0/1）；运行内存不回写配置文件，该值不随设备运行变化 |
| 数据类型 | `bool` / `uint16` / `int16` / `uint32` / `int32` / `float32` |
| 单位 | 如 `℃`、`%RH`，仅展示 |
| 描述 | 备注 |

## 批量导入

「从站寄存器」页提供**批量导入**：

1. 点击「批量导入」，可先**下载导入模板**
2. 上传 JSON 文件：可以是包含四类区的对象，也可以是某一区下的寄存器数组
3. 支持 `coils` / `discrete_inputs` / `input_registers` / `holding_registers` 四个键
4. 每条寄存器字段：`name`、`value`、`data_type`、`unit`、`description`
5. 导入前有**预览**确认；导入会覆盖所选类型下已有的寄存器数据

## 预留地址空间

Modbus 地址空间等于该区数组长度。若主站固定轮询 0–99，而实际只配置了个别地址，未扩容时主站读高地址会收到 `IllegalDataAddress` 异常。

在「从站寄存器」页使用**「预留地址空间」**把任意区扩容到目标长度：

- 只支持扩容，不支持缩减
- 设备整树导入时的 `space` 字段也起到同样作用，见 [[Device-Bundle-Format|设备包格式]]

## 功能码支持

主站可对本工具使用以下功能码：

| 功能码 | 操作 |
|---|---|
| `0x01` | 读线圈 |
| `0x02` | 读离散输入 |
| `0x03` | 读保持寄存器 |
| `0x04` | 读输入寄存器 |
| `0x05` | 写单个线圈 |
| `0x06` | 写单个寄存器 |
| `0x0F` | 写多个线圈 |
| `0x10` | 写多个寄存器 |

地址越界返回 `IllegalDataAddress` 异常，不支持的功能码返回 `IllegalFunction`。
