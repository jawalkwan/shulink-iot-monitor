# 注册包与心跳

## 半双工长连接模型

与真实 DTU 一致：注册包、心跳包、Modbus 请求 / 响应**共用同一条 TCP 长连接**，半双工收发，任一时刻只有一个方向在传数据。设备连接主站后：

1. 若开启「连接后自动发送注册包」（`send_on_startup`），连接成功即发送注册包
2. 若开启心跳，按设定周期（1–300 秒）发送心跳包
3. 主站可随时下发 Modbus 请求，设备按 Unit ID 路由到对应从站应答

## 报文数据类型

注册包与心跳报文均支持 8 种数据类型，按类型解析报文内容并转为字节流发送：

| 类型 | 内容格式 | 说明 |
|---|---|---|
| `Hex` | 十六进制字符串 | 如 `01000000000601030000000A`，可含空格与 `0x` 前缀，长度必须为偶数 |
| `String` | 任意文本 | 按 UTF-8 编码发送 |
| `Int8` / `Uint8` | 单个整数 | 1 字节，大端 |
| `Int16` / `Uint16` | 单个整数 | 2 字节，大端 |
| `Int32` / `Uint32` | 单个整数 | 4 字节，大端 |

## 配置入口

在设备「配置」页：

- **注册包**：报文内容 + 数据类型 + 「连接后自动发送」开关
- **心跳**：报文内容 + 数据类型 + 间隔（1–300 秒）+ 启用开关

## 与旧版本的差异

- 注册包 / 心跳配置为**设备级**（旧版本中从站级配置已统一收归设备级，旧文件导入时自动迁移）
- 默认示例报文（`01000000000601030000000A` 等）在导入旧文件时会被自动清理为空

## 验证方法

主站侧按原始字节流读取即可收到注册包 / 心跳。Python 示例：

```python
data = conn.recv(1024)
print("收到报文 HEX:", data.hex().upper())
```

或在应用「运行监控」页的通信日志中查看 `[REG]` / `[HB]` 前缀的收发记录。
