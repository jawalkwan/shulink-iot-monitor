# 设备与从站管理

## 三级模型

本工具采用 **设备（Device）→ 从站（Slave）→ 寄存器（Register）** 三级结构：

```
设备 Device（一台 DTU，一条到主站的 TCP 连接）
 ├─ 从站 Slave 1（Unit ID = 1，独立四类内存区）
 │    └─ 寄存器 / 线圈 条目（名称、初值、数据类型、单位、描述）
 ├─ 从站 Slave 2（Unit ID = 2）
 └─ ...
```

- 一台设备对应一条到主站的长连接（注册包 / 心跳 / Modbus 流量共用）
- 一台设备下可挂载多个从站，主站请求中的 **Unit ID** 决定路由到哪个从站的内存区
- Unit ID 取值范围 **1–247**

## 设备生命周期

| 状态 | 含义 |
|---|---|
| `Created` | 已创建，未启动（导入的设备一律回到此状态） |
| `Connecting` | 正在拨号连接主站 |
| `Connected` | 已连接，注册包 / 心跳 / Modbus 均在此连接上工作 |
| `Disconnected` | 连接断开（若开启自动重连会自动重拨） |
| `Error` | 连接错误 |

## 设备级配置

在设备「配置」页设置（详见 [快速上手](Quick-Start)）：

- 主站 IP / 端口
- 帧格式：Modbus TCP（MBAP）/ Modbus RTU over TCP（CRC16）
- 自动重连开关与重连间隔（1–300 秒）
- 注册包与心跳配置（见 [注册包与心跳](Registration-and-Heartbeat)）

## 从站配置

在「从站管理」页：

- **添加 / 编辑 / 删除**从站，同一设备内从站 ID 必须唯一
- 每个从站独立配置 **Unit ID** 与四类内存区（见 [寄存器配置](Register-Configuration)）
- 从站编辑与寄存器编辑使用**独立子窗口**，可同时打开多个互不干扰

## 多窗口编辑

从站编辑、从站寄存器、寄存器详情均在独立子窗口中打开，主窗口与子窗口数据实时同步；运行中的设备修改寄存器配置后同样即时生效。
